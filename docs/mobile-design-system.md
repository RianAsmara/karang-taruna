# RukunMuda Mobile Design System

## Design personality

Modern
Friendly
Community-oriented
Trustworthy
Youthful
Simple

## Avoid

Generic SaaS dashboard
Excessive cards
Excessive gradients
Excessive shadows
Corporate banking aesthetic
Dense tables
Too many colors
Decorative UI without purpose

## Layout

Mobile-first
8pt spacing system
Generous whitespace
Large touch targets
Clear hierarchy

## Typography

Display:
Large / bold

Section:
Semibold

Body:
Regular

Metadata:
Small / muted

Numbers:
Large / tabular where appropriate

## Finance

Income:
positive semantic color

Expense:
negative semantic color

Balance:
neutral / primary

Never rely on color alone.
